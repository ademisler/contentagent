# AI Content Agent

AI Content Agent is a WordPress content automation plugin with free and pro source trees in the same repository.

The root of this repository is organized around two distributable tracks:

- `Free/` - the WordPress.org-compliant free build
- `Pro/` - the extended pro build with advanced automation and licensing features

## Overview

AI Content Agent helps teams plan, draft, improve, and publish content from a single interface.
It combines AI-assisted writing, content workflow helpers, and WordPress-oriented publishing tools.

## Repository Layout

- `Free/` - free edition source, assets, and release packaging
- `Pro/` - pro edition source, assets, and release packaging
- `Free/plugin/` and `Pro/plugin/` - main plugin sources
- `Free/release/` and `Pro/release/` - distributable build outputs

## Highlights

- AI-assisted content creation
- WordPress admin integration
- Draft, publish, and planning workflows
- Release packaging scripts
- Clear separation between free and pro editions

## Development

Use the scripts and package files inside each edition directory to build or package the plugin version you need.

## Notes

- Keep generated release archives out of version control.
- Use the free edition for WordPress.org distribution.
